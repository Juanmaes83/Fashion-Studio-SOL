## Discrepancias README maestro ↔ realidad

1. **Outfits 45–55 %** es generoso: no hay entidad común ni UI en ninguna app; solo la skill y su manifiesto. Estimación realista: ~30 %.
2. **"Wardrobe: separación frontend/API/workers" pendiente** — correcto, pero conviene subrayar que la API actual **no arranca sin `npm run dev` de Vite**: no hay modo producción del pipeline.
3. **Un clon fresco de wardrobe está vacío** (data/ gitignorado): cualquier demo del vertical slice necesita fixtures o una sesión de importación con API key.
4. **Los pasos 2–4 del vertical slice (detección → crops → PNG aprobado) tienen coste OpenAI** y requieren `OPENAI_API_KEY`; no se pueden demostrar sin presupuesto aprobado (límite mensual "X" sin especificar en el encargo).
5. El README canónico referencia `docs/PRODUCT.md`, `ARCHITECTURE.md`, `ROADMAP.md`, `THIRD_PARTY.md` que **no existían** antes de esta rama; PRODUCT/ARCHITECTURE/ROADMAP siguen viviendo dentro del propio README (secciones 3, 6 y 14) y de momento **no se duplican** — regla del propio README: no crear estructura vacía para aparentar avance.
